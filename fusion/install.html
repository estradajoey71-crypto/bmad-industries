Installation guide

Not installable yet. Here is what it will take.

Today only the free BMAD Arcade launcher (public edition, without Fusions) is downloadable. This page states the real requirements so nobody is surprised later.

Download the free launcherJoin the Fusion waitlist

What a Fusion Alpha install will need (today's real requirements)

  • Linux x86_64. Tested only on Arch Linux with the Hyprland desktop; other desktops are untested (the session uses the desktop to find and place game windows). No Windows or macOS.
  • An NVIDIA GPU with at least 4.5 GB of free video memory and about 12 GB of RAM for GTA V + Minecraft.
  • Your own copies of the games: GTA V (Legacy edition, Story Mode; tested from the Epic Games Store through Heroic), Minecraft: Java Edition (your Microsoft account), Raft or Over The Top: WWI on Steam.
  • Script Hook V and the ASI Loader, downloaded by you from their author's site (freeware that may not be redistributed).
  • BMAD's own parts: the bridge, the GTA V script, the Minecraft mod and the Unity plugins. These are ours and are the only things we ship.
  • Nothing of yours is modified: Fusions run from separate BMAD profiles with their own prefixes and saves; your installs and saves stay untouched.

What the Fusion Alpha installer must do before release

  • Detect your supported game installations and check their versions against the tested ones.
  • Name every missing dependency with the exact fix.
  • Install only BMAD's own components; never a game file.
  • Create separate BMAD profiles so your original installs and saves stay untouched.
  • Configure the integration, launch it, and uninstall it cleanly with rollback.
  • Explain every error in plain words.

The Minecraft side already installs from inside the app (Mod Lab). The host-game side still uses developer scripts: that is the main reason there is no download.
