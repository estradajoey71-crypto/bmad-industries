Reference platform

  • OS: Linux x86_64
  • Desktop: Hyprland (only tested compositor; others untested)
  • GPU: NVIDIA with >= 4.5 GB free VRAM (session refuses otherwise)
  • RAM: >= 12 GB for GTA V + Minecraft
  • Stores tested: Grand Theft Auto V (Story Mode) via Epic via Heroic; Minecraft: Java Edition via Prism Launcher (Microsoft account); Raft via Steam; Over The Top: WWI via Steam
