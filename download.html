2. Verify, then run

Save SHA256SUMS beside your download. Open a terminal in that folder (usually Downloads) and check the file:

sha256sum -c SHA256SUMS --ignore-missing

Continue only when your downloaded file says OK. If it reports a mismatch, delete that download and get it again.

AppImage: make executable and open

chmod +x BMAD-Arcade-0.3.3-x86_64.AppImage
./BMAD-Arcade-0.3.3-x86_64.AppImage

Keep the file somewhere permanent to run it again. If you see a FUSE error, use this fallback:

./BMAD-Arcade-0.3.3-x86_64.AppImage --appimage-extract-and-run

Arch Linux: install with pacman

sudo pacman -U bmad-arcade-bin-0.3.3-1-x86_64.pkg.tar.zst
bmad-arcade

Tarball: install for your user

Install the required runtime libraries first, then:

tar -xzf bmad-arcade-0.3.3-linux-x86_64.tar.gz
cd bmad-arcade-0.3.3-linux-x86_64
./install.sh
~/.local/bin/bmad-arcade

No sudo for the installer. Keep the extracted folder: ./install.sh --rollback restores the previous executable after an upgrade; ./uninstall.sh removes the app and keeps your library.

3. Find a game and press Play

Already use Steam, Heroic or Lutris?

Keep those launchers installed and signed in. Arcade reads their installed games. Open a game in Arcade and press Play; check Launch check on its page if it does not start.

Bringing your own retro games?

Install a supported emulator, choose a folder containing your legally obtained game files and press Scan. Arcade includes no games, ROMs or BIOS files.

Quick fixes

Permission denied or nothing happens when I double-click

Run the two AppImage commands above from a terminal in the download folder. The first grants execute permission; the second shows any startup error. You do not need to run Arcade as root.

Missing libraries or GLIBC version error

The tarball uses your system libraries; see the dependency commands. A GLIBC version error means the system is too old for this build. Use a supported distribution; do not replace system libraries manually.

My library is empty or a game will not start

Make sure the game is installed through its original launcher, or scan the folder for your retro games. Arcade does not install Steam or bypass sign-in, DRM or anti-cheat. Share a diagnostics file with support if you need help.
