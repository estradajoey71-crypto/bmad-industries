# BMAD Arcade

**Every game you own, in one library, and a straight answer when one doesn't start.** A free game library and launcher
for Linux: Steam, Epic Games (through Heroic), GOG, Lutris, retro consoles through your installed emulators, and
programs you add. No account, no telemetry.

## Free, forever
- Unified game library (Steam, Heroic/Epic, GOG, Lutris, your own programs)
- Launch and track your installed games
- Retro consoles through your installed emulators
- Free and homebrew game downloads (open licences only)
- Movies and shows with resume
- Arcade Mode (controller, full screen)
- Controller navigation
- Diagnostics bundle
- Signed update notifications
