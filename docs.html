Getting started

1. Install

Download the AppImage, make it executable (chmod +x) and start it. Or use the tarball's ./install.sh, or the Arch package.

2. First run

Arcade detects Steam, Heroic and Lutris and the emulators you installed. Choose folders with your own legally obtained game files for retro consoles, then press Scan.

3. Play

Open a game and press Play. Arcade starts it through its own launcher and follows it. If it does not start, the game's page says why in Launch check.

4. Supporter licence

After purchase, download your licence from the account page, then in Arcade open Settings → About & updates → Add licence file. It is verified on your computer and works offline.

5. Updates

Arcade checks BMAD's signed release feed and tells you about new versions; it never installs anything by itself.

6. Diagnostics

Settings → About & updates → Create diagnostics file makes one readable file without saves, accounts or private titles. Attach it to a support request.

Uninstall

AppImage: delete the file. Tarball: ./uninstall.sh (keeps your library). Arch: sudo pacman -R bmad-arcade-bin.
