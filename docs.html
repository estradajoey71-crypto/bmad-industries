Install guide

System requirements

  • Linux on a 64-bit Intel/AMD PC (x86_64) with a graphical desktop (Wayland or X11).
  • A 2022-or-newer distribution (glibc 2.35+): Ubuntu 22.04+, Debian 12+, Fedora 36+, Arch Linux, or similar.
  • About 100 MB of disk space. Your games stay where your launchers installed them.

1. Download and check the file

Get a file from the download page. To confirm it arrived intact, put it next to SHA256SUMS and run sha256sum -c SHA256SUMS --ignore-missing; it should print OK.

2. Install — pick one

AppImage (any distribution):

chmod +x BMAD-Arcade-0.3.0-x86_64.AppImage
./BMAD-Arcade-0.3.0-x86_64.AppImage

It uses your desktop's own graphics, font and sound libraries, which every desktop already has. If it reports a FUSE error, install libfuse2 (Ubuntu 24.04: libfuse2t64) or start it with --appimage-extract-and-run.

Tarball (installs for your user, keeps the previous version):

tar -xzf bmad-arcade-0.3.0-linux-x86_64.tar.gz
cd bmad-arcade-0.3.0-linux-x86_64 && ./install.sh

It needs WebKitGTK 4.1, GTK 3, libsoup 3 and SDL2. Ubuntu/Debian: sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libsoup-3.0-0 libsdl2-2.0-0. Fedora: sudo dnf install webkit2gtk4.1 gtk3 libsoup3 SDL2. ./install.sh --rollback restores the previous version.

Arch Linux: sudo pacman -U bmad-arcade-bin-0.3.0-1-x86_64.pkg.tar.zst (pacman installs the dependencies).

3. First run

Arcade detects Steam, Heroic (Epic, GOG) and Lutris and the emulators you installed. For retro consoles, choose folders that hold your own legally obtained game files and press Scan. Arcade includes no games or ROMs.

4. Play

Open a game and press Play. Arcade starts it through its own launcher and follows it. If it does not start, the game's page says why under Launch check.

5. Early Access licence

After purchase you receive an email with a sign-in link to your account page, where you download your licence file. In Arcade open Settings → About & updates → Add licence file. It is checked on your computer and works offline; it unlocks BMAD Vault and custom backgrounds. Lost it? Sign in on the account page with your purchase email and download it again.

6. Updates

Arcade checks BMAD's signed release feed and tells you about new versions. Downloads are verified against the signed checksum; nothing installs by itself.

7. Diagnostics

Settings → About & updates → Create diagnostics file makes one readable file without saves, accounts or private titles. Attach it when you ask for help.

Uninstall

AppImage: delete the file. Tarball: ./uninstall.sh (keeps your library). Arch: sudo pacman -R bmad-arcade-bin. Your library and settings live in ~/.local/share/bmad-archive and ~/.config/bmad-archive if you want to remove them too.

Known limitations

  • Linux x86_64 only; no Windows, macOS or ARM builds.
  • Games that are online-only or blocked by anti-cheat on Linux may not run; Arcade says so instead of pretending.
  • Cross-game Fusions are in development and not included.
  • Physical 8BitDo button mapping is not yet verified on hardware; standard gamepads work.

What has been tested

Every release file is installed on clean systems before publishing: the tarball on Ubuntu 22.04 and Fedora 41, the AppImage on Debian 12 and Fedora 41, the Arch package on Arch Linux (checked from the command line: the app starts, runs in the free tier, activates a licence and removes it again). Day-to-day use, including real game launches, is tested on an Arch Linux desktop.
